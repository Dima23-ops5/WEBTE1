## O webe

Web je moja osobná vizitka, ktorá ma predstavuje ako študenta 3. ročníka bakalárskeho programu Aplikovaná informatika na FEI STU a Java vývojára. Návštevník sa dozvie, kto som, čo viem, čomu sa venujem, kedy mám čas a odkiaľ dochádzam.
